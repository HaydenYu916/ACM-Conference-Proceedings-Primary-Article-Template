# MobiSys working manuscript

Entry point: `main.tex` (pdfLaTeX). The numbered `mobisys-*.tex` files contain the paper sections. All referenced figures are in `images/`.

This commit contains the current manuscript and appendix as of 2026-10-27. The original ACM template files are retained. The manuscript is a working draft; physical closed-loop trials and some reproducibility details remain incomplete.

Local and Overleaf edits require an explicit GitHub synchronization step; they do not automatically synchronize through this chat.
